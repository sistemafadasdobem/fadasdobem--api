# Provider `agora/`

**Ficheiro:** `src/providers/agora/agora.client.js`

**Propósito:** geração de **token RTC** (`agora-access-token`), utilitários alinhados à API de sessões ao vivo (ex.: desligar participante / coerência com NCS conforme implementação actual).

**Variáveis:** `AGORA_APP_ID`, `AGORA_APP_CERTIFICATE`, chaves de **Customer ID / secret** se usadas para REST de gestão (ver ficheiro e `.env.example`).

**Feature:** `documentacao/features/Sessions.md`.
