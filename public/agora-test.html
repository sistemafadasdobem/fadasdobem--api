Mini Front — Homologação (1-a-1 · RTC publisher)

Como testar: (1) Login cliente → Criar sessão → Iniciar chamada (aceita câmara/micro). (2) Noutro browser, login taróloga → colar o session_id → Iniciar chamada. Ambos publicam áudio/vídeo; o token vem sempre como publisher pela API.

Sirva esta página no mesmo host que a API ou usa ?api=https://…. http://localhost:3000/agora-test.html (porta = PORT no .env). file:// ou Live Server noutra porta: preenche Raiz da API abaixo.

Configuração (servidor)

Deixa vazio se acedes a esta página já em http(s)://…/agora-test.html servida pelo app.js.

A iniciar…
Passo 1 — Login

Seeds: cliente e taróloga — emails no quadro de config após carregar a API; senhas no servidor (.env.example / homolog).

Passo 2 — Sessão

Faça login. O cliente cria a consulta; a taróloga não cria — cola aqui o ID da sessão (UUID) que o cliente vê nos logs.

O cliente deve enviar o texto depois de Sessão criada: (não o canal Agora, não o Specialist ID). Opcional: ?session=<uuid> na URL.

Passo 3 — Chamada 1-a-1 (RTC)

O backend devolve token publisher para os dois lados (micro + câmara). O pedido usa GET …/sessions/:id/token?role=publisher.

SDK: AgoraRTC.createClient({ mode: 'rtc', codec: 'vp8' }) — comunicação 1-a-1 (não live). Aceite câmara/micro ao clicar em Iniciar.
