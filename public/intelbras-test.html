Laboratório híbrido — WideVoice / Intelbras

As credenciais login e token WideVoice ficam apenas no servidor (.env). Esta página chama /api/v1/telecom/lab/* (ativar com INTELBRAS_TELECOM_LAB_ENABLED=true).

Abre em …/intelbras-test.html no mesmo host da API ou usa ?api=https://seu-servidor. Vídeo em produção costuma vir do softphone/WebRTC da central, não deste HTML — aqui validas a API (CHAMADA OK / ID).

Abriste o ficheiro em file://. Os botões não conseguem falar com a API. Corre a API (npm start) e abre no browser: http://localhost:3000/intelbras-test.html (ajusta porta no .env) ou preenche abaixo a raiz http://localhost:PORTA e «Guardar».
Fluxo rápido — já vem configurado pela BD (.env / seed)

Na pasta da API:
1) npm run seed:homolog — grava intelbras_ramal na taróloga + telefone no utilizador cliente (default 11999887766 — substitui no .env por INTELBRAS_LAB_DESTINO ou SEED_HOMOLOG_CLIENT_PHONE).
2) npm start — abre esta página em http://localhost:PORTA/intelbras-test.html.
3) Um clique em «Demo». O servidor dispara WideVoice (/lab/run-demo).

Click-to-call (vídeo/voz pela central)

Origem = número de ramal da taróloga na PABX WideVoice (não é o UUID na BD da app). Vem da Intelbras ou do painel do ramal (ex.: 2002). Destino = telefone do cliente com DDD (11999887766, 5511999887766 ou formato com espaços/travessões — o servidor usa só dígitos e aplica DDD local 11 vs prefixo 011 para outros DDD).

Liberar ramal usa o valor de Origem (mesmo campo do ramal).
